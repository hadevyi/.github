# Issue·PR 템플릿

## Issue Form

이 저장소는 작업·문서·설정·자동화·CI/CD Form을 제공합니다. 빈 Issue 생성은 비활성화합니다.

개별 저장소에는 선택한 Form 전체 묶음을 배치합니다. 중앙 Form과 개별 Form이 자동 병합되지는 않습니다.
Form의 기본 라벨은 생성 시 자동 지정되며 해당 라벨이 저장소에 먼저 존재해야 합니다.
담당자 지정은 Form에서 분리해 공통 Workflow로 처리합니다.

| 저장소 유형 | Form |
| --- | --- |
| 공통 GitHub 운영 | 작업·문서·설정·자동화·CI/CD |
| 브랜딩 사이트 | 기능·버그·개선·디자인·콘텐츠·배포 |
| 학습 | 도서·강의·공식문서·시험·튜토리얼·기타 학습 |
| 알고리즘 | 작업·기타 학습 |
| 프로필 | 콘텐츠·자동화·버그 |

## PR 템플릿

공통 PR 템플릿은 변경 목적·내용·Issue 연결·검증·체크리스트·참고 사항을 포함합니다.
별도 템플릿이 없는 저장소는 이 저장소의 기본 템플릿을 사용합니다.

- 중간 작업은 `Refs #번호`, Issue 전체 완료는 `Closes #번호`로 연결합니다.
- 구성된 CI와 체크리스트를 확인한 뒤 Merge commit으로 병합합니다.
- Dependabot PR은 Issue 연결과 체크리스트 의무에서 제외합니다.
